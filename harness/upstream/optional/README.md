# optional — layers you adopt one at a time

None of these is needed to run a round. Each names the origin repository's
own ecosystem (its sites, registries, personas and wiki farms) as the worked
example; the method in each travels, the names do not. Adopt a layer when the
rung you are on asks for it (README, "Adopt it in steps"):

- `SPECIALISATION.md` — dressing seats with personas and skills; the station
  pattern that lets instances multiply without drifting.
- `GRAPH.md` — the graph dialect: κ-addressed nodes, edges that a signature
  mints, the emitters in `tools/` (spellweb, star, emit_feed, vrc).
- `HOLONS.md` — content addressing: κ = sha256 of canonical JSON with the label
  excluded from its own preimage; sealed artefacts that re-derive anywhere.
- `WIKI.md` — publishing a harness's ledgers into a federated wiki.

References in these files to the origin's fleet, catalogue or chronicles
resolve upstream, at github.com/mitchuski/agentprivacy-harness.
