# chronicles — this repo's record

One file per session, `YYYY-MM-DD_slug.md`, verdict first, reversals recorded
with the same prominence as progress, ending in a handoff block. A session
without a chronicle is unfinished (GR-7).

**Empty by design.** This is the default distribution: the record starts with
you. The origin repository's chronicles are the worked example — read them in
date order to learn what the discipline feels like in practice.
