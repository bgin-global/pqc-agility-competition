# Support

| Need | Where |
|---|---|
| Discuss the competition, propose ideas, ask how to engage | [BGIN Discourse — IKP working group](https://bgin.discourse.group/c/working-group-s/identity-key-management-and-privacy), starting with the [IKP Post-Quantum Cryptography thread](https://bgin.discourse.group/t/ikp-post-quantum-cryptography-thread-06-26/1001) |
| Propose a metric, a scheme, a resource; offer a testbed node; nominate a committee member | GitHub issues here, using the templates |
| Committee, node-host, or entrant coordination that cannot be public (COI disclosures, recusals, node operations, submission logistics) | Private participants' Discourse — invitation from a convener; ask on the public thread or by issue labelled `access` |
| Something in this repository is wrong or broken | GitHub issue; a pull request is welcome (see `CONTRIBUTING.md`) |
| Security problem | `SECURITY.md` — private vulnerability reporting, never a public issue |
| Trouble signing commits | `docs/SIGNING.md` §8, then an issue labelled `signing` |
| Questions about the prize itself (eligibility, rules, awards) | The host (METI/NEDO) publishes the official call; until then, see `resources/briefing-digest.md` and ask on Discourse |

Maintainers answer on Discourse and in issues; there is no private support channel. Response target: one week during Phase A.
