# Maintainers

Maintainers hold the `maintain` permission on this repository, review pull requests as code owners, and cut signed tags. Conveners are the maintainers who also chair the evaluation committee (`GOVERNANCE.md`). Changes to this file go through a pull request approved by a convener.

## Becoming a maintainer

Sustained, reviewed contributions in one area (evaluation, testbed, governance) plus nomination by a convener and no objection from the other maintainers within one week. Every maintainer has a registered signing key listed in `.allowed_signers`.
