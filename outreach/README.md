## House style

- No salutation, no direct address. The forum is a working record, not correspondence.
- Short. The post carries the ask and the link; the repository carries the detail. Nothing of substance is stated only in a post.
- Every claim that has a source names it, and where sources disagree — the winner-selection date, for one — both are carried, attributed, rather than resolved in a post.
- Nothing is announced as settled that the committee has not ratified. Everything in the repository is `draft v0` until W1.
